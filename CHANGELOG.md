## Create: Enchantment Industry 2.5.0-preview.1 for Minecraft 1.20.1
Backported the complete 2.5 feature set to Forge and NeoForge 1.20.1 with Java 17, based on Create 6.0.8.

**Backup save before use!**
### Compatibility and known limitations
* This release supports Forge and NeoForge 1.20.1 using Forge 47.1.33 as their shared development baseline.
* Removed 1.4.1 content such as the Disenchanter and Experience Rotor is not remapped to unrelated 2.+ content.
