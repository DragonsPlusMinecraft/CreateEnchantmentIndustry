## Create: Enchantment Industry 2.5.0-alpha.1 for Minecraft 1.20.1
Backported the complete 2.5 feature set to Forge 47.4.10 and Java 17, based on Create 6.0.8.
### Compatibility and known limitations
* This release supports Forge 1.20.1 only. NeoForge 1.20.1 is not supported.
* Removed 1.4.1 content such as the Disenchanter and Experience Rotor is not remapped to unrelated 2.+ content.
